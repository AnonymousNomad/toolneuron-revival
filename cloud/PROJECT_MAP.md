# ToolNeuron Revival product map

## Cipher
Persistent local assistant identity. Honest slot states:
- EMPTY: no assistant model assigned.
- READY: a qualified model assigned and available.
Never imply an assistant exists when no model is loaded/qualified.

## Cipher's Laptop
Governed operational layer:
- persistent workspaces/projects;
- tasks and deterministic transitions;
- permissions/capability vocabulary;
- evidence and verification references;
- terminal execution;
- restart-safe state;
- worker/context packet assembly.

## Workstation shell
Desktop-like Android shell:
- windows;
- taskbar/dock;
- telemetry/status strip;
- skippable boot;
- recent/resume;
- canonical retro theme tokens;
- no blank home screen.

## Chat
Delegation surface, not an IDE. Show conversation, project chip, artifact/result cards and an obvious Open in Vibe Studio handoff. Do not duplicate editor/tree/log surfaces inside Chat.

## Vibe Studio
Workstation surface for creation:
- project tree;
- editor/generation loop;
- governed terminal/build actions;
- preview;
- capture/verification;
- artifact bundling;
- templates for app/web/game work.
Chat and Vibe share the same project/workspace.

## Files + Terminal
First-class windows over the same workspace. Terminal is app-owned PTY, no root, workspace-contained cwd, bounded output/process lifetime.

## Model Intelligence / Model Lab
Separate semantic role, runtime compatibility, task admission and device qualification. Model Lab runs repeatable batteries and shows evidence: PASS/FAIL/UNKNOWN, TTFT, tok/s, RSS/thermal where measured. Unknown stays UNKNOWN.

## Covert Engine runtime
Optional local runtime behind backend-neutral model contract. Preserve existing ToolNeuron inference runtime as another backend. No duplicate business logic per runtime.

## Creator / Creations
Newest owner direction makes this first-class.
Support:
- scripts/story plans;
- characters and reusable assets;
- scenes/shots;
- voice/audio;
- image/video provider adapters;
- episode/miniseries continuity;
- project asset library;
- export/render manifests;
- provenance/licensing metadata.
Use AnonymousNomad/covert-creation-studio as reference.

## ToolNeuron TV
Media/TV companion lane. Preserve legal-source/provider distinctions. No DRM bypass or pirate IPTV behavior.

## Game Station / Game Companion
Governed companion/control surface for games and our own game projects. Separate model intent/strategy from deterministic frame-rate mechanics.

## Covert Link / Local Routing Fabric
Cross-device/runtime architecture. Local-first, explicit identity, no silent fallback. Keep contracts stable even if transport implementation is staged.

## Continuity / Memory
Project, assistant and task continuity across sessions. Namespace boundaries; no silent cross-project memory leakage.

## Nexus / Foundry
Package/community ecosystem: verified packages, versions, hashes, provenance. Do not build marketplace complexity ahead of the local product loop.

## Community / Beta / Evidence
Discord, beta testers, GitHub releases, bug/device/model testing, evidence-first release notes, reproducible report bundles.

## Product order
Finish the full user journey before expanding architecture:
Start Center -> choose/import model -> occupy Cipher slot -> Chat -> create/open project -> Vibe/Files/Terminal -> build/preview/verify -> save/restart/resume -> publish/export.

Then finish Creator, TV/Game companion and ecosystem surfaces from the existing blueprints.
