# Publication outbox

When Cloud cannot directly publish because a credential or cross-repository permission is unavailable, do not stop product work.

Write final publication-ready artifacts here:
- discord/ — release, beta, known-issue and dev-update messages;
- site/ — exact website copy/patch notes;
- releases/ — release notes and artifact manifest.

Each artifact includes source SHA/version, evidence-backed claims only, intended destination, and the reason direct publication was unavailable.

Do not place credentials or private user data in the outbox.
